
# Student Result Processing System

## Description
This is a Go CLI application used to process and evaluate student results.

## Features
- Enter student details
- Enter five subject marks
- Calculate total marks
- Calculate average
- Assign grades
- Display Pass or Fail result

## Technologies Used
- Go Programming Language
- VS Code
- Git and GitHub

## Project Structure
- main.go
- student.go
- go.mod

## How to Run
1. Install Go.
2. Open the project folder.
3. Run the command:

go run .

## Output
The application displays student details, subject marks, total, average, grade and result.
